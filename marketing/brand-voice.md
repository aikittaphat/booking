# Brand Voice Guide

> คู่มือเสียงของแบรนด์ ใช้กับทุกข้อความที่ลูกค้าเห็น: เว็บไซต์, โพสต์โซเชียล, โฆษณา, อีเมล, LINE OA และข้อความตอบแชท
> Claude ทั้งสองบัญชีต้องอ่านไฟล์นี้ก่อนเขียน content ทุกครั้ง
> แก้ส่วนที่อยู่ใน `[วงเล็บเหลี่ยม]` ให้ตรงกับแบรนด์จริง

---

## 1. แบรนด์ของเราคือใคร

- **ชื่อแบรนด์:** ร้านฟื้นฟูโคมไฟหน้ารถ
- **ประโยคเดียวที่อธิบายแบรนด์:** ฟื้นฟูโคมไฟหน้ารถให้กลับมาเหมือนได้โคมมือ 1 ในราคาที่จับต้องได้
- **สิ่งที่ทำให้เราต่างจากคู่แข่ง:**
  1. [จุดเด่น 1]
  2. [จุดเด่น 2]
  3. [จุดเด่น 3]
- **ปัญหาของลูกค้าที่เราแก้:** [ลูกค้าเจออะไรอยู่ แล้วเราช่วยยังไง]

## 2. ลูกค้าของเรา

| | รายละเอียด |
|---|---|
| อายุ / เพศ | [เช่น 25–40 ปี, ส่วนใหญ่ผู้หญิง] |
| อาชีพ / รายได้ | [เช่น พนักงานออฟฟิศ, รายได้ 25,000–60,000 บาท] |
| อยู่ที่ไหน | [เช่น กรุงเทพฯ และหัวเมืองใหญ่] |
| ใช้ช่องทางไหน | [เช่น Instagram, TikTok, LINE] |
| สิ่งที่กังวล | [เช่น กลัวของปลอม, กลัวไม่คุ้มราคา] |
| สิ่งที่อยากได้ | [เช่น ของดีที่เชื่อถือได้ ส่งไว ราคาเหมาะสม] |

**เขียนเหมือนคุยกับ:** [ตั้งชื่อลูกค้าสมมติ 1 คน เช่น "คุณมิ้นท์ อายุ 29 ทำงานออฟฟิศ เลื่อนดู IG ช่วงพักเที่ยง"]

## 3. บุคลิกของแบรนด์

ถ้าแบรนด์เป็นคนหนึ่งคน เราจะเป็นคนแบบนี้:

| เราเป็น ✅ | แต่ไม่ใช่ ❌ |
|---|---|
| [เป็นกันเอง] | [ทะเล้นจนดูไม่น่าเชื่อถือ] |
| [รู้จริง] | [ใช้ศัพท์เทคนิคจนลูกค้าไม่เข้าใจ] |
| [จริงใจ] | [ขายของแรง กดดันให้ซื้อ] |
| [กระตือรือร้น] | [ใช้อีโมจิและเครื่องหมายตกใจเยอะเกินไป] |

## 4. วิธีเขียน

### สรรพนามและระดับภาษา
- **แทนตัวเอง:** [เรา / แอดมิน / ชื่อแบรนด์]
- **เรียกลูกค้า:** [คุณ / คุณลูกค้า / ชื่อเรียกเฉพาะ]
- **คำลงท้าย:** [ไม่ใช้ / ค่ะ / ครับ / นะคะ] แล้วใช้ให้เหมือนกันทุกช่องทาง
- **ระดับภาษา:** [ภาษาพูดที่สุภาพ ไม่ใช้ภาษาทางการแบบหนังสือราชการ]

### หลักการเขียน
1. **พูดถึงประโยชน์ที่ลูกค้าได้ ก่อนพูดถึงคุณสมบัติสินค้า**
   - ❌ "มี SPF50 PA++++"
   - ✅ "ออกแดดทั้งวันก็ไม่ต้องห่วง ด้วย SPF50 PA++++"
2. **ประโยคสั้น อ่านง่ายบนมือถือ** ย่อหน้าละไม่เกิน 2–3 บรรทัด
3. **ชัดเจน เจาะจง** ใช้ตัวเลขหรือข้อเท็จจริงแทนคำคลุมเครือ
   - ❌ "ส่งไวมาก"
   - ✅ "สั่งก่อนบ่าย 2 ส่งออกวันเดียวกัน"
4. **ทุกชิ้นงานต้องมี call to action ชัด ๆ 1 อย่าง** เช่น ทักแชท, กดสั่งซื้อ, ดูรายละเอียด
5. **อีโมจิ:** [ใช้ได้ไม่เกิน X ตัวต่อโพสต์ / ใช้เฉพาะ: ✨ 💛 👉]

### คำที่ใช้ / คำที่ห้ามใช้

| ใช้ ✅ | ห้ามใช้ ❌ | เหตุผล |
|---|---|---|
| [ชื่อสินค้าที่สะกดถูก] | [ชื่อที่สะกดผิดบ่อย] | ให้สะกดเหมือนกันทุกที่ |
| [ช่วยให้ผิวดูกระจ่างใสขึ้น] | ขาวใสใน 7 วัน, เห็นผล 100% | อ้างผลเกินจริง อาจผิดกฎโฆษณา (อย. / สคบ.) |
| [ราคาพิเศษ] | ถูกที่สุดในไทย | พิสูจน์ไม่ได้ |
| [ลูกค้าหลายคนบอกว่า...] | อันดับ 1 | ห้ามใช้ถ้าไม่มีหลักฐานอ้างอิง |
| [ ] | [คำที่ดูถูกคู่แข่ง] | ไม่ตรงกับบุคลิกแบรนด์ |

> ⚠️ **สินค้ากลุ่มอาหาร, อาหารเสริม, เครื่องสำอาง และสุขภาพ** มีข้อห้ามเรื่องคำโฆษณาตามกฎหมาย ห้ามอ้างว่ารักษาโรค และห้ามอ้างผลที่พิสูจน์ไม่ได้ ถ้าไม่แน่ใจให้ถามเจ้าของแบรนด์ก่อนเผยแพร่

## 5. ปรับโทนตามช่องทาง

เสียงของแบรนด์เหมือนเดิมทุกช่องทาง แต่ปรับ**ระดับ**ได้

| ช่องทาง | โทน | ความยาว | หมายเหตุ |
|---|---|---|---|
| เว็บไซต์ (หน้าสินค้า) | ให้ข้อมูล น่าเชื่อถือ | กลาง–ยาว | ใส่คำค้นหาสำหรับ SEO ให้เป็นธรรมชาติ |
| เว็บไซต์ (หน้าแรก / landing) | ดึงดูด ชัดเจน | สั้น | หัวข้อเดียวต้องบอกได้ว่าเราคือใคร ให้อะไร |
| Facebook | เป็นกันเอง เล่าเรื่อง | กลาง | บรรทัดแรกต้องหยุดนิ้วคนเลื่อนฟีด |
| Instagram | สวย สั้น | สั้น | caption สั้น ใส่แฮชแท็ก [X–Y] อัน |
| TikTok | สนุก เป็นธรรมชาติ | สั้นมาก | 3 วินาทีแรกต้องดึงคนดู |
| LINE OA | ใกล้ชิด เหมือนเพื่อนบอก | สั้น | ส่งไม่เกิน [X] ครั้งต่อสัปดาห์ |
| อีเมล | อบอุ่น มีประโยชน์ | กลาง | subject ไม่เกิน 40 ตัวอักษร |
| ตอบแชท / คอมเมนต์ | สุภาพ รวดเร็ว ช่วยเหลือ | สั้น | ขึ้นต้นด้วยการขอบคุณหรือรับทราบเสมอ |
| ข้อความในระบบ (ปุ่ม, error) | ชัดเจน สุภาพ | สั้นมาก | ห้ามโทษลูกค้า บอกเสมอว่าต้องทำอะไรต่อ |

## 6. ตัวอย่าง

### โพสต์โซเชียล
❌ **ไม่ใช่เสียงเรา:**
> โปรโมชั่นสุดคุ้ม!!! ลดราคา 50% ถูกที่สุดในประเทศ!!! รีบซื้อด่วน!!! 🔥🔥🔥🔥🔥

✅ **เสียงเรา:**
> [เขียนตัวอย่างโพสต์ที่ถูกโทน 3–5 บรรทัด]

### ข้อความ error บนเว็บ
❌ "ข้อมูลไม่ถูกต้อง"
✅ "เบอร์โทรต้องมี 10 หลัก ลองตรวจอีกครั้งนะคะ"

### ตอบคอมเมนต์ลูกค้าที่ไม่พอใจ
❌ "ทางร้านไม่ผิดค่ะ ขนส่งทำของเสียหายเอง"
✅ "ขอโทษจริง ๆ ค่ะที่ของถึงมือไม่สมบูรณ์ รบกวนทักแชทส่งรูปมาให้แอดมินหน่อยนะคะ เราจะรีบเปลี่ยนให้ใหม่ค่ะ"
